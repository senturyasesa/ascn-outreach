# ASCN Outreach

Инструмент точечной Telegram-рассылки по базе лидов с веб-дашбордом.
Мультиаккаунт, прокси, умное распределение сообщений, автоматическая проверка
ответов и лимитов, отчёты в Telegram-бота.

> **Данные (аккаунты, база, ключи) хранятся только на твоём сервере/компьютере
> и никуда не отправляются.** В репозитории — только код, без секретов.

---

## Возможности

- **Веб-дашборд** — вся работа через браузер, без терминала.
- **Мультиаккаунт + прокси** — каждый аккаунт через свой SOCKS5, round-robin.
- **Два режима рассылки** — персонально (каждому своё из базы) или единый текст всем.
- **AI-рерайт** — единый текст уникализируется под каждого лида (антиспам, OpenRouter).
- **Дневной планировщик** — задаёшь цель на день (например 50), демон сам растягивает
  её по рабочему окну и распределяет между аккаунтами с учётом дневных лимитов.
- **Автопроверка @SpamBot** — аккаунт словил флуд → сам идёт к @SpamBot, читает
  приговор, при ограничении морозится до даты и авто-возвращается по истечении срока.
- **Проверка ответов** — каждые 15 минут ловит ответы лидов, шлёт в Telegram-бота.
- **Вкладка «Ответы»** — мини-CRM: читаешь диалог и отвечаешь клиенту прямо с сайта.
- **ИИ-продажник** — по ответу лида генерит человечный черновик (ведёт на созвон) и шлёт
  в Telegram-бота с кнопками «✅ Отправить / ✏️ Редактировать / ✍️ Напишу сам». Промпт и база
  знаний в файлах, ключ — тот же OpenRouter. Отправку подтверждаешь ты, авто-send нет.
- **Статистика reply-rate** — вкладка «📈 Статистика»: отклик по базам и по аккаунтам.
- **Отчёты** — почасовые сводки в Telegram-бота (доставлено/цель, по аккаунтам, ответы, reply-rate).

## Стек

- Python 3.9+, Flask (веб), Telethon (Telegram), openpyxl (Excel), cryptography (шифрование хранилища).
- На сервере — systemd-сервисы + таймеры (рассылка, проверка ответов, отчёты).

## Установка

```bash
git clone git@github.com:senturyasesa/ascn-outreach.git
cd ascn-outreach
pip3 install -r requirements.txt
```

## Настройка (один раз)

1. **API-ключи Telegram** — получи `api_id` / `api_hash` на https://my.telegram.org
   (вводятся в онбординге при первом запуске, либо создай `data/config.json`
   по образцу `data/config.example.json`).

2. **Telegram-бот для уведомлений** — создай бота у @BotFather, добавь в свою группу,
   скопируй `.env.example` → `.env` и впиши токен и id чата:
   ```bash
   cp .env.example .env
   # затем впиши TG_BOT_TOKEN и TG_CHAT_ID
   ```

3. **Прокси** (опционально) — `data/proxies.json` по образцу `data/proxies.example.json`.

4. **База лидов** — положи `data/leads.xlsx` (структуру смотри в `data/leads.example.xlsx`).

## Запуск

**Локально (macOS):** двойной клик по **«Запуск.command»**
**Или в терминале:**
```bash
python3 app.py
```
Дашборд откроется на `http://127.0.0.1:8765`

## Развёртывание на сервере (одна команда)

```bash
git clone git@github.com:senturyasesa/ascn-outreach.git
cd ascn-outreach
sudo ./deploy/deploy.sh
```

`deploy.sh` сам поставит venv+зависимости, создаст папки/заготовки конфигов и
зарегистрирует все systemd-юниты (дашборд, демон рассылки, проверка ответов, отчёты).
Дальше заполняешь свои данные (api-ключи, аккаунты, прокси, база, текст) и включаешь
сервисы. Пошагово — **[DEPLOY.md](DEPLOY.md)**.

> Токены бота берутся из `.env` (в код не зашиты).

## Структура data/ (НЕ в репозитории)

| Файл | Что | В гите |
|---|---|---|
| `config.json` | api_id / api_hash | ❌ (есть `.example`) |
| `*.session` | авторизации аккаунтов | ❌ |
| `proxies.json` | прокси на аккаунт | ❌ (есть `.example`) |
| `rewrite.json` | ключ OpenRouter + промпт | ❌ (есть `.example`) |
| `leads.xlsx` | база лидов | ❌ (есть `.example`) |
| `accounts.json` / `limits.json` / `daily_plan.json` | рабочее состояние | ❌ |
| `replies.json` / `notified.json` / `sent_log.csv` | ответы и логи отправок | ❌ |
| `blacklist.json` / `freeze.json` | чёрный список и заморозки | ❌ |
| `ai_sales.json` / `ai_sales_prompt.txt` / `ai_sales_kb.md` | ИИ-продажник: конфиг / промпт / база | ❌ (есть `.example`) |
| `pending_drafts.json` / `bases.json` | очередь черновиков, базы для reply-rate | ❌ |

Всё это создаётся при работе и в репозиторий не попадает (см. `.gitignore`).
