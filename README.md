# ASCN Outreach

Локальный инструмент для точечной рассылки в Telegram по базе лидов.
Мультиаккаунт, прокси, распределение сообщений между аккаунтами, живые статусы, логи.
Всё через удобный веб-дашборд, без терминала и кода.

Данные (аккаунты, база, ключи) хранятся только у тебя на компьютере и никуда не отправляются.

---

## Что нужно
- **Python 3.9+** (проверь: `python3 --version`)
- Аккаунт(ы) Telegram, с которых будешь слать

## Установка (один раз)

1. Скачай проект:
```bash
git clone <ссылка-на-репозиторий>
cd ascn-outreach
```

2. Установи зависимости:
```bash
pip3 install -r requirements.txt
```

## Запуск

**macOS:** двойной клик по файлу **«Запуск.command»**
**Или в терминале (любая ОС):**
```bash
python3 app.py
```
Откроется браузер на `http://127.0.0.1:8765`

## Первый запуск: настройка (онбординг)

### Шаг 1. Получи api-ключи Telegram (бесплатно, 2 минуты)
Ключи нужны, чтобы программа могла работать с Telegram. Это делается один раз.

1. Открой **my.telegram.org** в браузере
2. Войди по своему номеру (код придёт в приложение Telegram)
3. Раздел **API development tools**
4. Заполни форму (App title и Short name латиницей, например «outreach»)
5. Скопируй **api_id** (число) и **api_hash** (строка ~32 символа)

### Шаг 2. Вставь ключи
На экране настройки впиши api_id и api_hash, нажми «Сохранить».
Ключи лягут в `data/config.json` (локально, у тебя).

### Шаг 3. Залогинь аккаунты
Вкладка **Аккаунты** → «Добавить аккаунт»:
- название (латиницей, например `akk1`)
- номер телефона
- прокси (необязательно, но желательно для нескольких аккаунтов)

Введёшь номер → придёт код (в приложение Telegram, если номер уже там; или SMS, если новый) → впишешь его → готово.

### Шаг 4. Загрузи базу лидов
База это файл `data/leads.xlsx` (при первом запуске создаётся из шаблона).
Правь её прямо на вкладке **Редактор** или открой в Excel.
Главные колонки: `ник` (кому слать) и `сообщение для захода` (что слать).

## Как пользоваться

- **Рассылка** — отмечаешь аккаунты, ставишь количество и паузу, жмёшь «Отправить». Сообщения расходятся по аккаунтам равномерно. Кнопка «Остановить» тормозит в любой момент.
- **Редактор** — правишь ников, боли и тексты сообщений, удаляешь контакты.
- **Логи** — кому, когда, с какого аккаунта ушло, дошло или нет.
- **Аккаунты** — логин, прокси, переименование, разлогин.

Учёт ведётся сам: одному человеку дважды не уйдёт, кому не удалось по постоянной причине (приватность/блок) — повторно не шлём.

---

## Важно

- **Темп.** Не гони много с одного аккаунта. 5-10 сообщений в день на аккаунт, лучше распределять по нескольким. Паузы между сообщениями уже стоят (90-240 сек).
- **Новые аккаунты** Telegram лимитирует жёстче. Свежий акк лучше «прогреть» (пожить пару дней) перед рассылкой и слать с него по чуть-чуть.
- **Прокси** для нескольких аккаунтов желателен: каждый акк на своём IP, чтобы Telegram не связывал их.
- Это инструмент для точечной работы, а не массового спама. За массовые рассылки Telegram банит аккаунты.

## Структура
```
app.py              сайт (дашборд)
send_campaign.py    движок рассылки
login.py            логин аккаунта из терминала (запасное)
data/               твои данные (в .gitignore, в репозиторий не попадают)
  config.json       api-ключи
  *.session         залогиненные аккаунты
  leads.xlsx        база лидов
  ...               логи, прокси, статусы
```
